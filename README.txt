STUDENT PROGRAM SYSTEM

Open index.html in Chrome.

Demo:
Admin    admin@gmail.com / admin123
Student  student@gmail.com / student123

WORKING CONNECTION:
1. Login as Admin.
2. Open Reports -> Add / Update Student Report.
3. Select Uday Kiran, enter marks/attendance/remarks and Save.
4. Logout.
5. Login as Student using student@gmail.com / student123.
6. Open Results or Reports. The admin's saved data is shown automatically.

Data is stored in browser localStorage, so admin/student are connected in this frontend prototype without a server.
